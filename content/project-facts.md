## 1. Регистрация / check-in — корп event (~100 чел.)

- **Тип:** корпоратив, вход по спискам
- **Масштаб:** ~100 человек
- **Подготовка:** список загрузили из Excel
- **Что пошло не так:** в последний момент добавились ещё сотрудники — использовали **ручной ввод** на стойке (реимпорт не успели)
- **Урок для copy:** Excel + импорт — основной путь; ручной ввод — не «костыль», а нормальный backup для last-minute

### Вставка для `/products/reg-point/`, `/articles/import-participants/`

> На корпоративе на ~100 человек список залили из Excel заранее. За день до event HR докинул ещё сотрудников — на повторный импорт времени не было, дошли через ручной ввод на входе.

## 2. Промо в ТЦ — чековая акция (15 арендаторов)

- **Формат:** торговый центр (не «сеть магазинов»), **15 точек** в белом списке по ИНН
- **Фрод участников:** шли в **Ашан** (гипермаркет рядом), набирали **стопки чеков**, регистрировались **в разные дни**
- **Операционная боль:** промо-агентство **придумывало контакты** и забивало их, чтобы **закрыть план по регистрациям**
- **Урок для copy:** антифрод по FN + «участник сам с телефона» + аудит заявок; без ФНС накрутка чеками не отловится

### Вставка для `/articles/promo-fns/`, `/scenarios/`

> В ТЦ с 15 арендаторами в белом списке главная боль была не «не тот ИНН». Участники таскали чеки из Ашана и пробовали регистрировать их несколько дней подряд. Отдельно — «план по регистрациям»: агентство придумывало контакты. Система не знает, что телефон выдуман — нужен процесс, не только софт.

## 3. Промо.Поинт без ФНС — застройщик / ЖК

- **Заказчик:** застройщик
- **Механика:** простая акция, **проверка чека не нужна**
- **Сценарий:** клиентское мероприятие для **жителей ЖК**
- **Цель базы:** продвижение **центра активностей** для резидентов (мастер-классы и пр.)
- **Итог:** Промо.Поинт подошёл; **не пожалели** — чековая механика не планировалась

### Вставка для `/products/promo-point/`

> Застройщик, мероприятие для жителей ЖК — чек не в механике. Промо.Поинт: форма, согласие, база ушла в CRM для центра активностей (мастер-классы, события для резидентов). Без ФНС здесь нормально; если бы добавили «приз за чек» — это уже Промо.Про.
