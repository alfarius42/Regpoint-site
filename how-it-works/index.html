Процесс

Как это работает

Регистрация на мероприятии и промоакция используют разные сценарии, но строятся вокруг одного и того же процесса: подготовка → автономная регистрация участника по QR → чистая база и отчёт без ручной обработки. Ниже — как это работает на каждом этапе.

Рег.Поинт

Импорт списка, регистрация, check-in на входе, отчёт по явке

Промо

Акция, сбор по QR, проверка чеков в моменте, розыгрыш, выгрузка

до 1 мин

Простой путь участника — без бумажных анкет на стойке

Понятный путь участника

QR, короткая форма, подтверждение на экране. Меньше диалога на стойке — быстрее вход и регистрация в акции.

Контроль для менеджера

Видны не только цифры регистраций, но и проблемные места: дубли, спорные чеки, статус check-in, готовность к выгрузке.

Надёжность на площадке

Сценарии собраны под типовые сбои: несколько входов, слабая связь, временный персонал и правка базы накануне события.

Для Промо.Поинт и Промо.Про

Промо.Поинт собирает заявки по QR без чеков. Промо.Про добавляет проверку чека через ФНС — шаг 03 в цепочке ниже. Оба модуля идут по одной схеме.

01

Создание акции

Менеджер задаёт период, правила, анкету и ограничения по участнику. Для чековых механик сразу настраивают магазины, минимальную сумму и лимит заявок — подробнее в сценариях промо с чеками.

02

Регистрация по QR

QR размещают на стойке, лендинге, витрине или в печатном носителе. Участник сам заполняет форму и принимает согласие на обработку ПД — промоутер помогает с механикой, а не перепечатывает данные (промо без очередей на стойке).

03

Проверка чеков

В Промо.Про чек сверяется с ФНС в момент загрузки: дата, ИНН, сумма, повторы (проверка чека через ФНС). Спорные заявки уходят на модерацию; при недоступности API подключается OCR fallback. В Промо.Поинт этот шаг пропускается.

04

Розыгрыш

После закрытия акции остаётся проверенная база: дубли и отклонённые заявки уже отфильтрованы. Розыгрыш или начисление бонусов идёт без ручной чистки таблиц.

05

Отчёты

Менеджер выгружает базу и сводный отчёт для заказчика: регистрации по точкам, статусы заявок, итоги розыгрыша. Данные не остаются у промоутера в личной форме — всё в одном контуре.

Для Рег.Поинт

Сценарий для конференций, корпоративов и форумов, где на входе нужен быстрый check-in без очереди к бумажному списку. Промо с чеками — во вкладке «Промо.Поинт / Промо.Про».

01

Импорт и предрегистрация

VIP-список загружают из Excel или открывают публичную регистрацию по ссылке. Перед событием база уже собрана — без правок накануне вручную (импорт участников из Excel).

02

Регистрация

Участник заполняет форму на лендинге или по QR, получает подтверждение и QR-код участника. Согласие на обработку ПД фиксируется вместе с заявкой — разбор типового пути: регистрация без очередей.

03

Check-in на входе

На площадке хостес сканирует QR: статус участника виден сразу, без сверки бумажных списков. Несколько входов работают параллельно; при нестабильной связи check-in продолжается по offline-сценарию (QR check-in на конференции).

04

Отчёты

После события — attendance-отчёт, сегменты (гости, VIP, спикеры) и выгрузка CSV для заказчика. Для regulated-сценариев согласования по ПД — в разделе 152-ФЗ и персональные данные.
