Промо.Про

Промоакции с проверкой чеков ФНС

Для акций «купи — зарегистрируй чек — получи приз». Автоматическая верификация через API ФНС (kkt-online) с OCR fallback.

Возможности

  • Всё из Рег.Поинт и Промо.Поинт
  • Проверка чека через API ФНС
  • OCR fallback (Tesseract.js)
  • QR-сканер чека, валидация ИНН, дат, суммы
  • Правило: один телефон — одна регистрация на акцию
