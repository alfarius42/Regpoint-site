Архитектура

Почему коробка, а не подписка на чужой облачный сервис

SaaS-регистраторы хранят базу участников у себя. Для многих заказчиков — банки, госкорпорации, pharma, крупные агентства — это неприемлемо: персональные данные должны оставаться на серверах клиента или его провайдера в РФ. Рег.Поинт поставляется как лицензия + Docker-compose: развёртывание на вашем VPS, обновления по подписке, данные под вашим контролем.

  • База MySQL на VPS заказчика — не shared multi-tenant
  • Соглашение об обработке ПД настраивается на каждое мероприятие
  • Роли director / manager с изоляцией доступа
  • Offline-capable check-in на площадке
$ docker-compose up -d
services:
  app:
    image: regpoint/app:latest
    ports: ["3000:3000"]
  db:
    image: mysql:8
    volumes:
      - ./data:/var/lib/mysql
  • VPS клиента, Linux, 2+ GB RAM
  • MySQL 8 — данные только на сервере заказчика
  • HTTPS + Let's Encrypt

Целевая аудитория

Кому подходит Рег.Поинт

Event- и BTL-агентства

Обслуживаете нескольких заказчиков — разворачиваете Рег.Поинт на VPS каждого клиента или на своей инфраструктуре с изоляцией данных.

Корпоративные организаторы

Банки, pharma, госкорпорации — у вас требования по локализации ПД. Self-hosted закрывает требования ИБ-отдела без согласования с SaaS-провайдером.

MICE-площадки и конгресс-бюро

Регулярные конференции, форумы, деловые встречи. Лицензия окупается за 2–3 мероприятия по сравнению с поштучной платой SaaS.

Маркетинговые агентства (BTL)

Промо с чеками ФНС, sampling, розыгрыши — Промо.Про закрывает весь стек верификации без сторонних API-прокси.

DevOps / Digital-отделы заказчика

Получаете Docker-compose + runbook. Деплой занимает 1–2 часа. Обновления — по расписанию вашей команды.

Агентства с требованиями 152-ФЗ

Согласие per-event, audit log, удаление ПД по запросу участника — без доработок и доп. тарифов.
