152-ФЗ на мероприятии: чеклист для организатора

Каждое мероприятие, где собираются ФИО, email и телефоны участников — обработка персональных данных по 152-ФЗ. Разбираем, что должен сделать организатор до, во время и после ивента.

Что считается персональными данными на мероприятии

ФИО, email, телефон, должность, компания — всё это ПД. Если вы регистрируете участников через форму, вы становитесь оператором ПД и обязаны соблюдать требования 152-ФЗ: получить согласие, обеспечить безопасность, ограничить доступ и дать возможность удалить данные по запросу.

Чеклист: до мероприятия

✓ Определён оператор ПД (юрлицо или ИП). ✓ Подготовлен текст согласия на обработку ПД — отдельно для каждого мероприятия, с указанием целей и срока хранения. ✓ На форме регистрации обязательный чекбокс с ссылкой на политику конфиденциальности. ✓ Определён ответственный за обработку ПД (DPO или назначенное лицо). ✓ Выбрана платформа с локализацией данных в РФ.

Чеклист: во время мероприятия

✓ Доступ к базе участников только у авторизованных сотрудников. ✓ Менеджеры на площадке видят маскированные данные (только имя + статус). ✓ Check-in через QR — никаких бумажных списков с полными данными. ✓ Offline-режим работает без передачи данных через публичные точки WiFi.

Чеклист: после мероприятия

✓ Установлен срок хранения данных (рекомендуется не более 1 года для участников, если нет иного основания). ✓ Обеспечена процедура удаления ПД по запросу участника. ✓ Audit log сохранён на случай проверки Роскомнадзора.

Как помогает Рег.Поинт

Все пункты чеклиста покрыты из коробки: согласие per-event, маскирование для manager, audit log, запрос удаления — без доплат и доработок. Данные хранятся на вашем сервере, что упрощает переговоры с корпоративными заказчиками.

FAQ

Нужна ли нотификация Роскомнадзора?

Да, операторы ПД обязаны уведомить РКН. Это отдельный процесс, не связанный напрямую с платформой регистрации.

Достаточно ли чекбокса на форме?

Чекбокс необходим, но текст согласия должен быть конкретным: цели обработки, срок хранения, перечень данных. Шаблоны — отдельный SKU в Рег.Поинт.

Нужна платформа с compliance 152-ФЗ из коробки?

Рег.Поинт — коробочная платформа. Данные на вашем сервере, 152-ФЗ из коробки.
